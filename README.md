## Python Calculator
A simple command-line calculator built with Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Exponent

## How to Run

- Install Python
- Run Terminal in Project Folder
- Run "python3 Calculator.py"
- Enter calculation
- To view history, clear history, or end the program, input "help"
